# 独立数学启发式：运行与模型对应

本分支的新入口是 `python -m src.smart_seat_allocator`。新搜索不调用旧启发式、列生成求解器、历史分配文件或生成器隐藏 witness；只读取座位图、旅客组和数学模型配置。旧实现用于对照实验。现有 `allocation_visualizer.py` 的默认算法也已切换到新实现，文件加载适配器为 `src/model_driven_seat_allocator.py`；若要重现旧图，可显式传入 `--algorithm src/heuristic_seat_allocator.py`。

## 安装与运行

```bash
.venv/bin/python -m pip install -r requirements.txt -r requirements-smart.txt

.venv/bin/python -m src.smart_seat_allocator \
  --groups data/generator_v3_2/benchmark_v2_2026-10-07/cases/v2_wb333_to_wb343_load97_large_groups_mixed_r0_groups.json \
  --old-seatmap data/generator_v3_2/benchmark_v2_2026-10-07/seatmaps/3-3-3seatmap.json \
  --new-seatmap data/generator_v3_2/benchmark_v2_2026-10-07/seatmaps/3-4-3seatmap.json \
  --time-limit 60 --workers 8 --seed 42 --progress \
  --output outputs/smart/demo.json
```

OR-Tools CP-SAT、HiGHS、NumPy 与 SciPy 是新路线的依赖，不要求 Gurobi 或其许可证。

Python 接口：

```python
from src.smart_seat_allocator import solve
result = solve(new_seats, old_seats, groups, weights, config,
               time_limit=60, workers=8, seed=42)
```

也提供 `run_allocation(...) -> (result, elapsed_seconds)` 兼容接口，通过 `config['smart_heuristic']` 的 `time_limit / workers / seed` 调整预算，默认 20 秒、8 个搜索线程、seed 42。

## 本轮选档与迭代

本文的“新算法初版”（早先称“基础版”）指本分支重新构建的数学启发式，不是项目原有的 C++ 或旧 Python 算法。A 是在新算法初版上增加几何缓存的版本；B、C 是两个简化试验，并非三次累计提高分数的升级。

以 V2 72 例为主要实验：其中 69 例可行、3 例经独立结构性证书证明不可行。基础 5 / 20 / 60 秒分别找到 68 / 69 / 69 例完整合法解；距本轮三档最好已知分数不超过 1% 的分别为 32 / 42 / 68 例。因此本轮选择 **60 秒上限**作为优先改进档位，命令行建议显式指定 `--time-limit 60`。这是当前实现的实验选择，不是问题的理论最低耗时，也不是全局最优保证。

真正采用的改进是几何排序缓存：在一次求解内部按舱位计算稳定邻居排序，不同资源需求复用前缀；NumPy 对座位编号排名排序、去重。221 组对照的几何候选集合完全相同。几何生成微基准由 2.6303 秒降至 0.7029 秒，约 3.74 倍；整个求解器的加速不能直接套用该倍数。

为检验复杂度，在预先选定的 6 个 V2 难例上比较了三种 60 秒版本：

| 版本 | 相对基础版胜 / 平 / 负 | 合计分数变化 | 完整合法 / 超时 |
|---|---:|---:|---:|
| A：缓存 + 完整搜索 | 6 / 0 / 0 | +197.1459 | 6 / 0 |
| B：缓存 + 单后端 + 短重组 | 6 / 0 / 0 | +72.8751 | 6 / 0 |
| C：再删除候选扩充、模式变形和重复重组 | 6 / 0 / 0 | +136.4661 | 6 / 0 |

本轮选择 A，再单独冻结源码做完整 V2 验证。C 相对 A 是 4 胜 / 0 平 / 2 负，但两个退步例抵消了其余提升，总分低 60.6798 分；选择 A 不意味着它在这六例中逐例都更好。B 同时改变后端与时间分配，不能把差异全归因于 HiGHS；单次六例开发比较也不能证明每个保留算子单独必要。所有开发结果和源码独立归档，不逐例选择多个版本的最好分数。完整分项与轨迹见 HTML 报告。

最终 A 的 V2 全量验证已完成：69 个可行输入全部得到完整合法解，另外 3 个有独立不可行证书，无未解决输入、无超时，最大求解耗时 59.8171 秒。相对新算法初版 60 秒，22 胜 / 33 平 / 14 负，合计提高 322.0066 分，逐例等权平均扣分降低 0.3969%。相对本机历史 C++ 原始源码 5 秒，54 胜 / 5 平 / 10 负，平均扣分降低 3.6108%；相对旧 Python 5 秒，68 个共同合法例全部提高，平均降低 9.3331%。后两项有时间预算差异，C++ 还有线程数差异。V2 已证全局最优的完整解仍为 0。

同一 A 源码、seed 和预算也观察到重复运行波动：开发六例合计提高 197.1459 分，最终全量批次中对应六例提高 123.4993 分。最明显的 `wb343_to_wb333 / load97 / large_groups`，开发时提高 87.4497 分，最终提高 3.0940 分。这说明墙钟截断和多线程条件下单次开发收益不能直接外推；最终表完整保留全量批次，不用开发最高分替换。

## 算法

算法类型是 **matheuristic（组合数学启发式）**：几何模式与匹配负责构造，受限整数优化负责联合重组，直接模型负责大邻域修复。它不依赖训练数据、神经网络、历史解或生成器 witness。

1. **独立分舱与结构性不可行检查。** 保留完整座位图坐标，将不存在跨舱耦合的舱位拆分，共享一个总时限；混舱目标排退回联合模型。先检查固定座位之后的婴儿—成人座位对最大匹配：即使放松其他约束仍容量不足时，直接给出不可行证书。
2. **完整组模式。** 在实际可用座位上，以多种长宽比例生成紧凑资源形状及带备用位置的形状。固定乘客与确定保护空座先保留，本组锚点并入可移动资源形状。先给所有组最多 12 个成功形状，再均衡追加最多 60 个；初始构造按不超过 5 秒的共同时间尺度分配预算。较长运行获得完整解后，另用最多 2 秒为每组继续生成最多 180 个成功形状。
3. **特殊枚举与 Hungarian 匹配。** 特殊乘客有限枚举，普通成人在给定剩余占座集合上做最小成本匹配。陪护位置必须由合格成人占据，允许同一成人在几何关系成立时照顾多个同组儿童。保护空座不可共享。
4. **快速构造。** 位集实现资源与条件 SSR 冲突判断，后悔值优先安置缺少替代方案的组。密集问题先尝试限时回溯装箱；普通组晚放，缺少模式时根据真实剩余空座重新拟合。不完整的合法构造可作为直接模型的提示，但不是可交付结果。
5. **模式联合选择。** 初始模式池在所有预算下用 CP-SAT 求解。每组保留成本最低的 48 个模式及排覆盖；资源需求达到容量 95% 时扩大到 96 个及排／子排覆盖；始终保留当前完整解的确切模式。仅在子问题预算至少 10 秒、总剩余时间还多出至少 10 秒时采用 HiGHS 全池重组：长运行的前段可分配 10–12 秒，其余重组继续用 CP-SAT 紧凑池。20 秒档和各档的尾段均避免启动大池 HiGHS，以限制预处理和关闭超时。
6. **向量化成人下降。** 同时评分普通成人之间的交换及向空座迁移，精确计算个体目标、原始重心最大偏差及跨组婴儿影响；保留所有必要陪护支持。它快速消除简单换座损失，再让整数优化处理复杂组合。
7. **模式变形。** 受保护乘客与独占保护座块协同迁移、整组资源形状平移、单个资源位置替换；对每个新形状重新匹配身份，加入模式池联合选择。
8. **自适应大邻域。** 选择局部损失大的根组，交替释放单个目标模式或多个目标模式的阻塞组；考虑保护资源所有者。停滞时扩大邻域，穿插随机组、顺序覆盖，并定期为已释放旅客开放完整座位域；其他组仍锁定，因此这种修复通常不是完整问题的全域求解。每个根组至少争取释放其他组，避免大组单独被锁在满载局部最优。
9. **可行性恢复与独立验收。** 无完整模式组合时退回稀疏直接模型，再必要时解完整硬约束模型。只接受全员分配、零硬违规、分数严格改善的完整解。每次验收都调用原项目评估器，而不是直接相信优化器辅助变量的目标。

`src/seat_model.py` 是从列生成模块提取的无搜索公共模型信息层；原 `src/cg_gurobi/instance.py` 保留兼容导出。这里复用的是可行域、拓扑和业务参数，不是旧搜索逻辑。

## 数学目标与证书

原模型的距离、座位价值、偏好、同行组紧凑度和婴儿影响均保留。同行组的重心最大偏差通过

\[
 n_g D_g=\max_p |n_g X_p-\sum_q X_q|
\]

的整数坐标上图形式（正负方向各一条下界不等式）建模，纵向同理。它不是行跨度或组内距离和的替代指标。SSR 隔离仍是“激活后每种 SSR 各至多一人”，不是不同 SSR 类型一概不能同排。

HiGHS 模式重组使用原始浮点目标；CP-SAT 使用整数目标系数。直接模型按组人数公倍数提高系数精度，并累计一个保守的舍入误差上界；若获得全域下界，转换回最大化软分时加入该误差，避免产生过紧上界。

- `status=complete`：全员分配、硬违规为 0。
- `status=no_solution`：预算内未找到完整方案；**不代表输入不可行**。
- `status=infeasible`：直接全域模型或必要座位对匹配证书证明不可行；明显的无效输入在模型入口抛出 `ValueError`。
- `total_score`：独立评估器的原始浮点分数。
- `upper_bound`：只有直接全域模型提供的安全上界；缺少全域证据时为 `null`。
- `proven_optimal`：全域上界与可行分数在 `optimality_tolerance=1e-6` 内闭合。
- `stages[*].pool_bound`：仅当前模式池整数优化的界，不能当作原问题的上界。
- `history`：同一次运行中严格改善的可行解轨迹。

候选集、枚举节点和邻域受限，因此这是一种数学启发式，不能承诺所有大实例在固定时限内达到全局最优。小实例优先运行全域模型，允许在提前证明最优后立即返回。

## 时间与复现

时间控制有三层：总截止时间、各阶段子预算和自适应搜索强度。求解入口使用单调墙钟；独立舱位共享总时限。每次 CP-SAT 搜索的时间上限是阶段预算与总剩余时间的较小值，构模循环也检查总截止点。初始构造按至多 5 秒的共同尺度分配；更长预算用于追加候选与更多局部迭代。LNS 在停滞时扩大释放范围，单次优化通常给 0.15 或 0.45 秒，达到截止点前始终保存本次运行的最好完整合法解。它不是只靠固定迭代次数估计运行时间，也不通过放宽模型约束来提速。

`solve(..., on_improvement=callback)` 可在新完整合法解通过验收后报告时间与分数，命令行 `--progress` 会显示这些改善。60 秒是最终返回的搜索上限，并不表示直到 60 秒才发现第一份方案；但回调不是提前返回接口。若调用必须在 5 秒内结束，应直接传入 5 秒上限。根据历史轨迹看到后续没有改善，不能倒推出当时已经知道可以安全提前终止。

`time_limit` 覆盖模型准备、候选构造、求解和最终审计。直接模型在构造过程中检查截止时间，并为结束和审计预留时间。原生求解器结束操作仍不能随时强制中断，实际耗时以 `wall_seconds` 为准；实验单列超预算记录。磁盘读写、命令行导入及进程启动不计入这个函数内部计时。

HiGHS 重组使用单线程，`workers` 控制初始 CP-SAT 和直接模型的搜索线程；30 秒以上舱位子问题的后续模式重组固定为单线程，减少短子预算末端的多线程退出延迟。多线程 CP-SAT 和墙钟截止会受系统调度影响；固定 seed 不等于逐位、逐次相同结果。`workers=1` 可降低这种波动，但也可能降低限时解质量。不同预算的独立运行之间不保证单调；同一次运行始终保存已找到的最佳合法解。
