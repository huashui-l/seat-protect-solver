# 列生成（`src/exact_column_generation.py`）正确性审计

- 审计对象：分支 `codex/alignment-corrections`，工作树 `30306d8`
- 审计方式：代码通读 + 穷举反例复现（非仅阅读推断）
- 环境：`.venv`（Python 3.12.13 + highspy），47 个核心测试通过
- 复现脚本：`/tmp/repro_cg01.py`、`/tmp/repro_cg02b.py`、`/tmp/repro_cg03b.py`、`/tmp/repro_h2b.py`、`/tmp/repro_infeasible.py`
- 结论：**列生成的 LP 证书层存在多处已复现缺陷，`proven_optimal` 与精确 U 目前不可信；整数解 `I` 的验证链安全。**

## 一、已复现缺陷

### H1（高）定价 DFS 把 `best_rc` 当作域最小检验数上报
- 位置：`:2545-2547`（cutoff 恒为 `-tolerance`）、`:2668`（`complete = aborted_reason is None`）、`:2704-2706`（`reduced_cost_lower_bound = best_rc if complete else root_reduced_cost_lower_bound`）、`:2255-2290`（历史 incumbent 播种）
- 机制：`stop_on_negative=True` 时所有下界 ≥ `-tol` 的子树被整块剪掉，"完成"只证明无负列，不证明最小值。`best_rc` 取自实际访问的叶子。
- 复现（2 排 6 座、3 人组、历史候选第 2 排）：

  | 组对偶 | 穷举真实最小 | DFS 报告下界 | proven_optimal |
  |---|---|---|---|
  | 0.0 | 0.0 | 0.6 | True |
  | -0.3 | 0.3 | 0.9 | True |
  | -0.6 | 0.6 | 1.2 | True |

  对照 `stop_on_negative=False` 时报告值与穷举一致。精确轮固定使用 `stop_on_negative=True`（`:6093`）。
- 外溢：假下界写入锚点（`:5851-5905`，仅检查 `isfinite`）→ `_transport_pricing_lower_bound` 迁移（`:1050-1142`）→ 命中 `transported_nonnegative` 的组被剔除出 `exact_jobs`（`:6076-6079`）。已复现：以 π=0 的假界 0.6 为锚点，新对偶 π=0.3 时搬运值 0.3 ≥ `-tol`，而真实最小检验数为 -0.3，存在负列却被永久跳过。
- 最严重后果：若所有组都被这样剔除，`:6094-6101` 直接置 `exact_certified=True`，零次精确定价即认证；经 `:6394`、`:6447-6449` 传播到 `:7352-7359` 的 `proven`，可输出 `proven_optimal=True` 与 `complete_column_space_lp_bound_certified=True`。
- 修复：`:2704` 改为 `min(best_rc, -tolerance) if complete else root_reduced_cost_lower_bound`，并把"证无负列"与"证最小值"拆成两个字段。

### H2（高）搬运界的 SSR 条件标志项键错位
- 位置：`:1094-1103` 构造 3 元组键 `(gid, kind, location)`，而 `duals.ssr_flag` 实际为 4 元组 `(gid, kind, location, ssr)`（`:4529`）。
- 后果：查不到即恒取 0，标志对偶变化被全部漏掉。
- 复现（含 `sameRowNoOtherSSR=Y` 的 3 人组）：旧 flag 对偶 -4.0 → 新 0.0 时，真实最小检验数 0.0，搬运结果 0.4，**高于真实值**，非严格下界。对偶下降方向安全。
- 影响面：仅限带条件 SSR 隔离标志的组，但一旦发生即与 H1 同路径破坏证书。
- 修复：按 4 元组键遍历，系数上界按每乘客 1 计。

### H3（高，对应原 CG-02）DFS 历史候选未过分支域
- 位置：`:2252-2292` 只校验资源互斥与陪护，未校验 `forced_placements` / `forbidden_placements`；各旅客裁剪只在 `domains`（`:2043-2055`）发生，而 incumbent 取自 `workspace["option_by_signature"]`（全集）。
- 复现（强制旅客 0 坐 2A）：DFS 报告 rc=-10.0、`proven_optimal=True`，返回列 `[1A,1B,1C]` 违反强制；域内真实最优 -9.8。禁止分支同理。调度器 `price_group_exact` 原样透传（`:4432-4437`）。
- 后果：错误值成为该节点的 `best_rc` 与剪枝阈值；`stop_on_negative=False` 的升级轮用 `cutoff = best_rc - tol`，可能剪掉域内更优解并"证明最优"。
- 加重项：`:5720-5758` 只在该组存在被允许的列池方案时才重播 `historical_mip_start`，否则子节点继承父节点旧 start，再次越域播种。对照 `historical_patterns` 预热路径（`:4277-4284`）已做域过滤，说明仅 DFS 一处遗漏。
- 修复：incumbent 候选加 `forced ⊆ sig and forbiddden ∩ sig = ∅`；子节点进入时清空 `historical_mip_start`。

### M1（中）快速轮用平滑对偶写入精确轮 incumbent
- 位置：`:2596-2601` 无条件 `cache.historical_mip_start = pattern.signature`；快速轮使用 `discovery_duals`（`:5725`）且不认证（`:5988-5993`）。
- 后果：把"平滑对偶下更小、真对偶下更大"的方案设为精确轮 incumbent，直接放大 H1。
- 修复：快速轮禁止写 `historical_mip_start`。

### M2（中）分支域不可行时下界语义不一致
- 位置：DFS `:2790-2799`、MIP `:3184-3202` 返回 `proven_optimal=True` 但 `lb=-inf`；小组 `:4108-4116` 与 DP 返回 `+inf`。
- 复现：3 人组强制两人同座 → MIP 给 `-inf`；1 人组禁止全部放置 → 小组给 `+inf`。一个本应剪枝的节点会使该轮安全界退化为 None。
- 修复：统一返回 `+inf`。

### M3（中）安全界低于可行解时静默跳过
- 位置：`:6339-6360`、终局扫描 `:7236-7240`。`candidate_upper >= heuristic_score - tol` 只是赋值前置条件，不满足时无日志、无标志、不撤销认证。
- 该矛盾只可能来自无效下界，属于最强的一致性信号却未被使用。
- 修复：置 `root_lp_certified=False`、`all_nodes_certified=False`，记录 `bound_contradiction`；`:7385`、`:7924` 对负 gap 断言。

### M4（中）其他界处理
- `:6282` 升级轮 `exact_lower_bounds.update(...)` 会用更弱下界覆盖首轮更强下界，应取 `max`。
- `:4436` 调度器 `max(DFS, MIP)` 会把 H1 的假值抬高 MIP 的合法界；应仅在 DFS 返回根松弛时参与。
- `:1022-1029` 无穷下界直接返回 `None`，使安全 U 从"有界但松"退化为"无 U"（保守方向）。

### L1（低）CG-03 满载等式与可变资源不一致（仅非默认配置）
- `:4445-4460` 按每名双侧保护旅客固定 +2 计数，`:4689-4694` 据此启用座位行等式强化；但 `require_two_real_neighbors=False` 时边缘座位只消耗 2 个资源（`:731-738`）。
- 复现：1 排 3 座、固定 1A 双侧保护，`demand=3/3` 触发等式强化，合法列只消耗 `{1A,1B}`，独立评估器判合法而主问题会排除它。
- 默认配置（`require_two=True`）下固定旅客在预处理阶段直接报错，不会静默出错。

### L2（低）双旗旅客放置域语义不一致
- `:727/739` 用 `if both ... elif single`，只建双侧资源；评估器独立检查两项，子排邻座 ⊆ 双侧邻座，故双旗旅客在评估器口径下必然违规。生成器会拒绝该输入，但求解器入口未拒绝。

### L3（低）其他
- `:6110` 锚点迁移读侧未判 `master.phase_one`，写入侧（`:5861`）有守卫，属脆弱依赖。
- `:2338-2346` `physical_option_key` 用 `round(individual_cost, 12)` 判定旅客可互换，退化时 `:4045` 的 `symmetry_rank` 反查可能 `KeyError`。
- `:6632-6635` 终局扫描吞异常无日志；`run_column_generation` 分舱默认时限（`:7681`，60 秒）与 `_limits`（`:450`，3600 秒）不一致。

## 二、已核对判定正确的部分

- 主问题建模：组凸性等式、座位容量行、条件 SSR 激活与计数线性化、婴儿影响的同组抵消、Phase I 人工列及其"完整定价后仍为正才判不可行"逻辑，与数学模型及独立评估器一致。
- 放置域：舱位、固定座位、出口排、摇篮、过道、单双侧保护（含跨过道语义与"一空座不能保护两人"）、陪护邻接，逐条与评估器一致。
- DFS 下界分项（`lower_bound`，`:2500-2538`）：恒定项、独立放置项、矩形跨度项均为真下界；`stop_on_negative=False` 路径的 `cutoff` 均为真下界，故该路径 `complete=True` 时 `best_rc` 确为域最小。
- 对称性消除（`:2300-2400`）：固定座位、旧座位、SSR、陪护差异经域或指纹分化，未发现删除真最优的情形。
- MIP 路径下界取 `info.mip_dual_bound - π_g`（`:3200-3209`、`:3505-3512`），`kObjectiveTarget` 截停时不冒充证书。
- 小组精确定价、标签 DP（含 `objective_audit_mismatch` 自校验）、配对精确定价：下界为真界，且按分支域过滤域。
- 整数解 `I`：所有整数解经独立评估器复核，违规即拒、不优不换；`I` 不会劣于暖启动。
- 分舱聚合：界求和要求全舱证书，缺一舱即 `None`（但一舱错则整体错，见 H1 外溢）。
- 对偶使用：认证轮一律使用原始 `lp.duals`，平滑仅用于发现列。
